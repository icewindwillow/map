两种底图

手账总览：随网页附带的真实海岸线数据，可拖动、缩放；它经过概括化，不是街道或测绘级地图。陆地颜色不表示国家归属，周边岛屿和国家仅作地理参照。

街道底图：按需加载 MapLibre GL JS 与 OpenFreeMap。需要联网；加载失败时会保留总览，不会变成一张空白页面。

地图来源与隐私

总览：GSHHG 2.3.6 / basemap-data 2.0.0（LGPL-3.0-or-later），海岸线来源与转换脚本随代码提供。在线底图：OpenFreeMap / OpenMapTiles / OpenStreetMap contributors。

本站没有登录、定位和分析追踪。点击街道底图后，浏览器会连接地图服务与脚本 CDN。公开仓库或公开网址不适合存放私密地址、未获同意的照片；禁止搜索引擎收录不等于访问加密。
