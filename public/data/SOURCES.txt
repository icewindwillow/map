Modifications for this project:
- Intermediate-resolution data clipped to longitude -17..12, latitude 46..65.
- Kept all available intermediate-resolution land and water polygons (area_thresh=0).
- Included available country-border line segments from the same package.
- Converted source coordinates to GeoJSON WGS84 [longitude, latitude].
- Rounded coordinates to 5 decimal places for storage. This does NOT imply survey accuracy.
- Removed irrelevant attributes; added feature kind/level and provenance metadata.
- No illustrative/manual coastline points were added.

The readable GeoJSON itself is supplied as editable source data.
The extraction source code is included in scripts/generate-geography.py in the project package.
This is generalized geographical overview data, not current navigation, street,
property, or survey data. It has not been individually audited for every small island.
Neighbouring land uses the same neutral fill; fill does not imply UK membership.

DEMO LOCATION DATA
The 8 demo coordinates are approximate city-centre reference points, not verified event
locations, and do not assert that the recipient visited any of the cities.
No personal travel dates or photographs were supplied or invented.
