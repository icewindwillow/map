# v0.5.1 地名搜索

作者页主要流程：输入地名，点击搜索，核对候选地址，选中并新增，填写故事后保存草稿或发布。也可将候选位置用于当前地点，保留照片与评价。经纬度在高级定位中备用。

经站点所有者同意接入 Photon 公共地名服务：https://photon.komoot.io 。仅主动提交的查询发送给服务商，不发送登录令牌、邮箱、故事或照片；避免查询私人地址。不进行输入联想请求。常用中文别名转换为英文，其他地名建议英文名称加城市。

接口 POST /author/api/search 使用现有 Access 身份验证和 CSRF 防护。D1 自动创建独立搜索缓存表和限流表，缓存七天，上游查询全站串行并间隔至少两秒。无需 API key 或手动迁移，不修改原故事表。公共服务无可用性保证，错误保留编辑内容，可继续地图选点。

服务文档：https://github.com/komoot/photon/blob/master/docs/api-v1.md
