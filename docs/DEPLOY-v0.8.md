# v0.8 城市、官方介绍与游客评价

沿用现有 Pages 构建命令 `exit 0`、输出目录 `public` 和 D1 `DB` 绑定，无需新增环境变量。游客表和限流表会在首次请求时自动以 `CREATE TABLE IF NOT EXISTS` 初始化，不重写原有作者评价、照片或地点记录。

- 编辑室：所属城市／城镇可修改；官方介绍及 HTTPS 来源链接与 `description` 作者长评分别保存。空长评仍隐藏。
- 首页：按城市筛选，卡片和相册显示城市。现有地点由原地址映射补齐城市，阿加莎故居保留待确认。明确保存的城市优先于自动标签。
- 游客：输入公开署名、1–5 整星评分及选填的 2000 字评论。姓名不经过身份验证，游客平均分与作者评分互不影响。
- 作者：选中地点后在“游客评论管理”删除指定评论。服务器验证 Access 身份、允许名单、请求来源及 CSRF。删除是软删除，公开列表与平均分立即排除，数据库保留审计记录。
- 基础防滥用：同源 JSON、长度限制、隐藏诱捕字段、按连接 IP 每分钟一次／每天二十次。限流表只存每日变化的 IP 摘要而非原始 IP，过期限流记录随提交清理。此措施不是实名验证或强机器人防护；大量公开流量时可另行接入 Turnstile。
- 评论按最新排序，每页 20 条，可加载更多；重试沿用提交 ID，避免网络错误造成重复评价。

官方介绍未自动抓取或生成，请作者填写并注明来源。游客提交测试仅在本地 SQLite 夹具运行，未向正式站点写入测试评价。

验证：`npm run check`；本地 `tests-v04/editor-browser.mjs` 和 `tests-v04/guests-browser.mjs`；Pages Functions 构建。
