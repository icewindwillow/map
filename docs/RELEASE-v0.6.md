# v0.6 分类、评分配色与聚合展开

五种核心分类使用统一细线 SVG：博物馆、修道院、城堡、教堂、美术馆。其他原有类型保留，使用通用定位图标；宫殿与城堡及桥梁显示为城堡类，展览显示为博物馆类，原始文字不被改写。编辑器提供分类选择，保存草稿或发布后持久化；公开列表支持类别筛选。

评分：0–1.5 陶土色、2–3 赭金色、3.5–4 鼠尾草绿、4.5–5 松绿，未评分灰绿。颜色附加于明确的星星、分数与文字，不作为唯一语义。聚合点中性显示数量，不推算评分。

坐标审计：爱丁堡 9 个条目（含港口皇家游艇），其中市中心 8 个均为不同坐标。唯一共用参考坐标是 Bodleian 图书馆与馆内印刷工坊；两处未确认地点仍为 null。线上公开 API 无覆盖记录。此次不修改任何坐标。

聚合根因：总览缩放上限 18 倍，fit 原固定经纬度边距 .6/.5 度且最大 12 倍，市中心相近地点无法展开。改为按实际范围留边，提高上限；同址或最大缩放处提供可选记录列表。总览仍是简化海岸线，并非详细街道地图。

验证：68 项单元/路由测试；编辑器类别保存、照片/发布/筛选回归；电脑城市八点展开；手机子聚合可继续展开；图书馆/工坊同址选择。
