# 照片审核台 v1

入口 `/photo-studio/`，作者后台“照片相册”可直接进入。全部素材在浏览器处理，视频自动跳过，原文件不会被移动或修改。没有接入云端 AI 或自动调用收费服务。

1. 选择已有地点对应的文件夹（支持 JPEG / PNG / WebP）；技术初选最多 15 张。填写准确的网站地点 ID。
2. 入选卡片支持完整大图、横框裁切预览、换图、拖动及按钮排序、名称和注释编辑、选片反馈。备选库可搜索文件名。
3. 每张勾选“画面、地点与说明已核对”。改图、改备注、改地点 ID 后需要重审；重排顺序不丢失审核。
4. 点击导出发布包。作者后台选择同一地点，导入 JSON，自动下载原内容备份，全部图片成功上传后才替换编辑中的相册。
5. 最终仍需点击作者后台的“发布到地图”。这一步沿用原有 Access 登录、CSRF、版本冲突保护和每地点 15 张限制。

## 保存与边界

- IndexedDB 自动保存当前项目，包括网页大小图片。浏览器清理数据会丢失自动保存，请导出“备份审核项目”作长期备份。打开新项目会提醒备份当前项目。
- 技术分仅参考细节、曝光、横框适配、分辨率；同图近似哈希用于减少重复。它不识别人脸、游客或房间，也不会自动编写未经核实的历史。新照片文案为空，需要人工核对。示例推荐来自 Codex 逐图查看。
- 跨项目偏好学习、EXIF/GPS 自动地点匹配、联网找图、云端 AI 语义评分暂未接入。当前每次由用户选定一个地点文件夹。
- 网图先下载再导入，不用外链作为展示图。来源可在审核项目中保留 `credit` / `sourceUrl`。
- 导入失败保留编辑中的原相册；已上传的部分素材仍是未发布私有素材。重试可能生成重复私有素材。
- 发布包含压缩后的 JPEG，无原片 EXIF，最多 200 KB/张。旧版照片资源不会删除。当前版本沿用已有后台图片存储和缩略图展示方式。

## 本地示例

`node scripts/serve-photo-studio.mjs /absolute/path/to/manifest.json`

浏览 `http://127.0.0.1:8795/photo-studio/`，点击“加载 Britannia 示例”。manifest 的 `format` 为 `atlas-photo-project-v1`，包含 `place`、`placeId`、`selected`（有序 ID 列表）和 `items`（含 ID、文件名、data 本地图片 URL、名称、说明）。仅本地启动时提供 manifest，不把完整备选库发布到网站。
