# 精选与查证工作流

1. 用户导入最多 15 张自己的精选照片，全部入选并锁定，保留原顺序。
2. 添加同一地点的完整相册作为备选。视频跳过；相同压缩内容去重，不覆盖照片文字与个人记忆。
3. 在“我的记忆、场景与查证”填写线索。点击补选时保留锁定精选，剩余名额按技术分及近似图过滤填充，最多 15 张。技术补选不能保证场景多样性或识别游客，需要人工检查。
4. 导出待辨认资料。下载的 JSON 含照片、用户记忆与固定照片 ID；没有自动发送网络请求。交给 Codex，按 travel-photo-captions 技能看图和查询来源。
5. Codex 返回以下 JSON。导入只更新文字、类别、辨认状态，不替换图片或改变精选、个人记忆；更新的照片重新审核。

```json
{
  "format": "atlas-photo-research-v1",
  "placeId": "royal-yacht-britannia",
  "photos": [{
    "id": "原资料中的照片ID",
    "title": "核实后的具体名称",
    "note": "对象是什么、为什么特别；只有可支持的事实",
    "scene": "特色展品",
    "identity": "已确认",
    "evidence": "依据及查证范围；用户回忆和历史事实分开记录",
    "researchUrl": "https://example.com/verified-source"
  }]
}
```

类别：待分类、外观与全貌、景观与庭院、核心空间、特色展品、人物与故事、生活与后勤。
辨认状态：待核实、已确认、仅描述可见画面。
未能确定身份时保留“待核实”；若用户决定用保守名称，则选择“仅描述可见画面”，删除未经核实的身份或故事。

6. 按场景安排顺序（同类别保留原顺序），之后仍可拖动调整。
7. 每张确认后导出发布包，作者后台导入并发布。个人记忆、查证依据和资料链接不会自动公开，网页图片来源仍单独填写。

旧审核项目兼容加载。工具没有内置付费模型、自动联网搜索或无人审核发布。
